Welcome to the **Rental Car** project! This is a complete website for a car rental business, featuring a beautiful modern design, easy booking for customers, and a powerful dashboard for the owner (Admin).

---

## 📂 What's Inside?
This project is split into two simple parts:

1.  **Frontend (The "Face"):** Found in the `frontend` folder. This is the actual website that people see and click on. Built with React and Tailwind CSS.
2.  **Backend (The "Brain"):** Found in the `backend` folder. This part handles the database, saves your bookings, and sends emails. Built with Node.js and MySQL.


## ✨ Features
*   **Customer Booking:** Users can browse cars, check prices, and book directly.
*   **Admin Dashboard:** Manage your cars, see all bookings, and confirm or cancel them.
*   **Email Alerts:** Automatic emails to both you and your customers when a booking is made.
*   **Mobile Friendly:** The website looks perfect on phones, tablets, and computers.
*   **Modern Design:** High-quality images and smooth animations.

---

## 🛠 Tech Stack (For Geeks)
*   **Frontend:** React, Vite, Framer Motion, Tailwind CSS, Lucide Icons.
*   **Backend:** Express, Prisma (MySQL), Multer, Nodemailer, Firebase (Push).
*   **Database:** MySQL.
